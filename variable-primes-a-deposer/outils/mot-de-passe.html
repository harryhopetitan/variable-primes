Définir un nouveau mot de passe

Le projet contient des données chiffrées (js/donnees.js) : utilisez plutôt outils/changer-mot-de-passe.py, qui les rechiffre. Cette page ne sert que pour un site sans données.

Le mot de passe n'est pas enregistré : cette page calcule son empreinte, à coller dans js/config.js à la place du bloc acces. Rien n'est envoyé sur Internet.

Après modification, toutes les sessions ouvertes devront saisir le nouveau mot de passe.
